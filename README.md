# Supporting Information

This repository contains additional supporting information for the manuscript:

**Current Status and Future Developments in Computational Prediction of Synergistic Anticancer Drug Combinations**

Yanhao Zhu, Di Su, Hua Wang, and Juntao Liu

## Contents

The supporting information includes:

- **Supplementary Note 1** — Detailed formulations and calculation procedures for commonly used drug-combination synergy metrics, including Bliss independence, HSA, Loewe additivity, ZIP, NCI-ALMANAC ComboScore, and combination index.

- **Supplementary Note 2** — Definitions and formulas for commonly used evaluation metrics for computational drug-combination prediction, including RMSE, MAE, R², Pearson correlation, Spearman correlation, accuracy, precision, recall, F1 score, AUROC, and AUPRC.

- **Supplementary Tables S1–S4** — A comprehensive comparison of computational models for synergistic drug-combination prediction, organized according to four modeling paradigms:
  1. Direct phenotypic mapping
  2. Relational inference
  3. Target- and network-mediated modeling
  4. Dose-dependent combination-response modeling

The tables summarize prediction tasks, combination datasets, drug information, cancer-context information, additional biological or pharmacological information, modeling strategies, and interpretability characteristics.
